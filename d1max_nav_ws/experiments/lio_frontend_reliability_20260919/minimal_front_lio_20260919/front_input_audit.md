# 单前雷达＋内置 IMU：输入与坐标约定审查

本节是建图对照前的独立离线输入审查，不是建图成功报告。只读取已有缓存、源代码及已完成实验的日志；没有启动 ROS、连接机器狗、修改默认参数或重建安装库。完整数值、单位、计算口径和来源哈希见 [front_input_audit.json](front_input_audit.json)。同目录标定候选与后续运行结果需分别验收。

## 1. 为什么值得做这组对照

单前雷达＋其内置 IMU 能减少中心 IMU 相对时差、名义长杆臂和 IMU—IMU 拟合等变量，但**不能预先认定内置 IMU 更好**。本包前内置 IMU 的长缺口明显更多，只是精确重复值较少。

同一包 `slam_raw_20260917_171716_fe8f38`，按旧对照首个配对点云 header `1772316441199985920 ns` 起的 `[0,180 s)` 取数据；中心 IMU 使用现有实验的 −13 ms 偏移，前内置 IMU 不添加偏移。没有重采样、补帧或去重复。

| 指标 | 前雷达内置 IMU | 中心 IMU |
| --- | ---: | ---: |
| 实际消息数 | 34,696 | 35,311 |
| 首末 header 有效平均频率 | 192.817 Hz | 196.232 Hz |
| header 周期中位数 | 4.999936 ms | 4.999416 ms |
| 大于 30 ms 的间隔 | 104 | 83 |
| 大于 50 ms 的间隔 | 77 | 1 |
| 最大间隔 | 105.016 ms | 59.990 ms |
| 相邻六轴完全相同 | 0 对 | 3,422 对（9.691%） |
| header 非递增 / 非有限六轴 | 0 / 0 | 0 / 0 |

频率是记录消息频率，不是硬件采样率认证。缺口也不能仅凭 bag 定位到硬件、驱动、网络或录包端。不得为了让前 IMU 对照跑完而偷偷放宽断档阈值。

## 2. 原始前 IMU 的单位与初始化

前 IMU 首个 header 起固定 2 秒有 399 条消息，中心为 401 条。所有值都保留，以下仅为低动态段描述，没有独立静止真值，也不等于算法最终接纳的完整初始化批次。

| 固定首 2 秒统计 | 前内置 IMU | 中心 IMU |
| --- | ---: | ---: |
| 原始加速度均值模长 | 1.002385 | 0.999722 |
| 加速度逐轴标准差，换算 m/s² | 0.03949 / 0.02194 / 0.01044 | 0.00467 / 0.00474 / 0.00581 |
| 角速度均值模长 | 0.009667 rad/s | 0.001071 rad/s |
| 角速度逐轴标准差 rad/s | 0.000827 / 0.001044 / 0.000707 | 0.000652 / 0.000666 / 0.000620 |

前 IMU 初始加速度主要沿原始 **+Y**，中心主要沿原始 **−Z**。两者是不同的原始轴，不应把同名或近似位置当作同坐标。

- 前原始加速度按 g 尺度乘 `9.80665`，角速度保留 rad/s、不再做度转弧度。原始量级和 [RoboSense 官方 AIRY 解码器](https://github.com/RoboSense-LiDAR/rs_driver/blob/main/src/rs_driver/driver/decoder/decoder_RSAIRY.hpp) 的量程转换相符，但官方上游代码不等于录包时实机驱动构建证明。
- 不使用固定 `[0,0,0,1]` 姿态作为观测；初始化使用六轴矢量，输出适配消息应将 orientation 标为不可用。
- 前 IMU 的实验基线保留原 header、offset=0。中心 −13 ms 是相对前 IMU 的经验修正，**不能搬到前 IMU 上**。这不宣称前点云—前 IMU 的绝对时差已完成标定。
- 当前静止初始化要求至少 300 条、2 秒，平均加速度模长 8～12 m/s²；不乘 `9.80665` 的约 1g 原始量会被该门限拒绝。
- 归一化后内部再乘的是 `9.81 / 初始均值模长`，本段前 IMU 约 0.997962、中心约 1.000620；不是把加速度重复乘一次 9.8。

陀螺均值会作为初始 `bg`，单个姿态不能独立辨识完整加速度偏置和安装角。因此不把前 IMU 较大的初始陀螺均值直接等同于未补偿漂移，也不把中心较小波动等同于硬件精度更高。

## 3. 新旧坐标表达必须成套切换

定义 L 为前雷达原始点坐标，N 为当前归一化点坐标，F 为前内置 IMU 原始矢量轴，I 为旧适配器转轴后的 IMU。列向量约定为 `p_target = R_target_source p_source + t_target_source`。当前 N 与 L 同原点。

旧适配器使用 `A = Rx(+90°)`，即 `(x,y,z) → (x,−z,y)`：

| 输入方式 | LIO 使用的 R | LIO 使用的 t |
| --- | --- | --- |
| 旧转轴 IMU，复现历史单位外参 | `R_I_N = I` | `0` |
| 原始轴 IMU，等价复现历史外参 | `R_F_N = Aᵀ` | `0` |
| 原始轴 IMU，使用本机 DIFOP 候选 | `R_F_N = R_F_L(device) · R_N_Lᵀ` | `t_F_L(device)` |
| 仍保留旧转轴 IMU，使用相同 DIFOP 候选 | `R_I_N = A · R_F_N` | `A · t_F_N` |

本机前雷达候选 SN 为 `3009bede1530`，原始 q/t 来自此前实读 DIFOP。原始轴候选 R/t 的具体数值保存在 JSON；相对旧链旋转改变约 0.578253°。候选仍以“DIFOP 方向和实际驱动输出基底解释正确”为前提，不是正式标定认证。

**不能**让适配器旋转一次 A，又把针对 raw F 的外参原样送入滤波器，否则矢量轴与外参就不配套。修改 body frame 名字也不会实际旋转数据。

几何等价不保证导出的世界 XY 每一项完全相同：`FromTwoVectors` 对不同 body 基底选择最小对齐旋转，世界 yaw 可差一个常量。用本段均值复算，raw F 与旧 A 表达的初始世界差主要是 **−0.15987° yaw**，roll/pitch 约为数值零。对照 XY 要统一世界规约；这项 yaw 差不会使 Z 产生下沉。

## 4. 实际前端的初始化和去畸变

实际使用库为 `install/faster_lio/lib/libfaster_lio_lib.so`，SHA256 为 `8f7a66b4a545a24fce4ba36cbc9764e16e8a2b9f5361833a376738831111f069`，ELF Build ID 为 `ce6fe7fc25ed48300ab621a0f2e497a109c43db8`。已完成 baseline 的 [runtime_binary_check.json](../runs/extrinsic_baseline_180s_20260919/runtime_binary_check.json) 记录了 `/proc/PID/maps` 中实际加载的该文件。

- `include/imu_processing.hpp:166–181`：用初始平均加速度确定重力；`gravity_aligned_world=true` 时旋转初始 IMU 姿态，使世界重力沿 −Z，整个点云、里程计和 TF 共用这个世界坐标。不应在导出 PCD 时再转一次。
- 这一步只建立世界“竖直”，**不标定缺失的 LiDAR—IMU 安装角**，也没有将真实地面强制水平。重力方向仍是滤波器两自由度状态，不是之后永久冻结。
- `imu_processing.hpp:234–269`：用相邻 IMU 端点均值和实际 dt 传播，减去状态中的偏置，转到世界后加重力。
- `imu_processing.hpp:301–314`：点时间 curvature 为毫秒，再除以 1000；点先通过给定 `R_I_L/t_I_L` 到 IMU，沿运动传播，然后回到扫描末端的 LiDAR。虽然历史注释写着“only rotation”，实际公式含平移、速度、加速度和杆臂。
- 初始化完成后，配置中的加速度/角速度协方差替换初始样本协方差；不是直接融合消息中的零 covariance。

版本边界必须保留：上述初始化/去畸变头文件时间早于该安装库且与实际启动日志对应；工作区当前 `laser_mapping.cc` 已含后来独立构建的输入防护修改，**不能据当前源码存在 guard 就说默认安装库已启用 guard**。默认普通建图路径仍可能跨长 IMU 缺口传播，本组结果不能称为连续性认证通过。

另有一个小的一致性项：`common_lib.h` 加速度归一化常量为 9.81，`use-ikfom.hpp` 的 S2 重力固定模长为 9.809，差 0.001 m/s²。理想静止且 ba=0 时对应极小的向上残差，并非已证明的严重向下漂移原因；本次单变量传感器对照应保持它不变，不顺手混入算法改动。

## 5. 对照的验收边界

同一批点云、同一前端二进制、同一时间窗口、无回环和无场景约束；只改变明示的 IMU 来源及与之配套的单位、坐标链和时间约定。比较时至少核对实际接纳的点云时间序列、初始化完成时刻、前端状态有限性、沿程高度变化、匹配残差与保存地图。

本审查不输出“已修好”的结论，不将走平地的先验写入估计器，不掩盖前 IMU 长缺口。最终改善与否必须由后续真实离线运行结果决定。

# Faster-LIO 初始化、噪声模型与默认二进制审计

日期：2026-09-20。范围：离线只读对照本地 Git 基线、当前源码、默认安装库和既有 180 秒实验日志；没有运行 ROS、回放、编译生产安装或改变参数。

## 结论与优先级

本次没有找到可直接解释持续下沉的单一模型代码错误。**没有证据支持把重力估计冻结，或把 gravity_aligned_world 的初始协方差转换认定为 bug。**

| 优先级 | 结论 | 应对 |
|---|---|---|
| P1 | 默认安装库没有新的建图 IMU 连续性 guard；已录入的较长缺口仍可能进入平均端点传播和扫描末端外推 | 首先把缺口/点时间与实际积分区间关联；不能把工作区新防护当作已生效，也不能据此单独宣称下沉根因已找到 |
| P1 | acc_cov/gyr_cov/b_*_cov 是直接送入 Q 的数值，不是随后平方的标准差；Q 以 dt² 形式进入预测 | 在调参前统一方差、噪声密度、采样率约定。现值是有效调参量，不是从该 IMU 实测辨识得到的认证值 |
| P2 | 单姿态静止均值不能独立分离加速度零偏、比例误差和重力方向；当前 ba 初值为 0，但随后可估计 | 保留联合状态与跨运动验证，不能把初始均值直接当作无偏重力真值；不要仅据短静止数据填入三轴 ba |
| P3 | 加速度归一化常量 9.81 与 S2 固定模长 9.809 相差 0.001 m/s² | 小的一致性项，理想 ba=0 静止残差方向为向上；不是已证实的严重下沉解释。不要混入外参单变量试验 |

另外，Git 基线中确有残差拒绝/邻点复用风险，**但本次实际默认库已经包含相应修复**，不能再把它们当作“昨天运行尚未修复”的根因。

## 2. gravity_aligned_world：初始 P 与 S2 切空间

路径：`imu_processing.hpp:166` 附近，`IMUInit` 用平均加速度求一个旋转 C，使初始 IMU 向上的加速度方向转到世界 +Z：

- 原规约：R₀=I，g₀=−9.809·mean(a)/|mean(a)|。
- 对齐规约：R₀=C，g₀=(0,0,−9.809)。
- 外参仍留在 IMU 本体系中，不随世界左乘 C 旋转。
- `change_x(init_state)` 后，代码重新设置一份全新的、分块各向同性、无交叉项的初始 P，并调用 `change_P`，不是旋转某个已经收敛且有交叉相关的旧 P。

这里 SO(3) 误差为右局部坐标。对世界左乘 C 不改变这个局部姿态误差；位置/速度的各向同性块经过 C 仍不变。重力 2×2 初始块是 `1e-5 I`；相同模长球面的两个正交切平面坐标之间转换保持该各向同性块不变。

`S2.hpp` 的 Bx/Nx/Mx 都从当前重力向量计算，`change_x` 中保存的 S2 索引列表只是状态布局，不是旧方向的切空间数值缓存。预测和迭代更新还会计算新旧切空间之间的转换。

用中心轴/前雷达轴两个代表性均值做纯坐标代数复核，新的 `T P Tᵀ` 与直接重置 P 的最大元素差分别约 7.2e-13 和 2.2e-16（见 JSON）。这不是运行编译滤波器的单元测试，但支持上述坐标推导。

**边界：若将来在运行过程中动态重置重力或旋转世界，已有非各向同性 P、交叉协方差、地图和轨迹都必须一致变换；不能把这里的“初始化重新给 P”外推为运行时可任意改 g。**

## 3. 噪声参数与权重到底如何使用

源码链为：

`LoadParams → SetAccCov/SetGyrCov → cov_*_scale_ → Q 的对角线 → predict`

在初始化中虽然计算了初始样本协方差，初始化结束随即用配置 `cov_acc_scale_/cov_gyr_scale_` 覆盖。因此静止门控通过、消息自带 covariance 或初始样本方差，都不意味着最终 Q 已自动取到该 IMU 的实测噪声。

三组均配置：

- `acc_cov=0.1`、`gyr_cov=0.1`；
- `b_acc_cov=0.0001`、`b_gyr_cov=0.0001`；
- 点面量测方差常量 `LASER_POINT_COV=0.001`。

前四者直接填入 Q，未再平方。若按输入样本方差解释，0.1 对应标准差约 0.31623，分别使用 (m/s²)² 与 (rad/s)²；0.001 m² 对应点面标准差约 3.16 cm。不能把“期望标准差 0.1”原样填为该参数并称等价。

IKFoM 预测实际使用：

`P_next = F P Fᵀ + (dt G) Q (dt G)ᵀ`

因此连续时间白噪声功率谱密度、每采样点方差和这里的 Q 不是不加说明就能互换的量；若做噪声密度标定，需明确离散化和频率，不能仅把 Allan 标准差直接粘入。固定 Q 下，改变实际 dt 或出现长缺口也会改变传播权重。该形式沿用上游模型，本轮没有依据把它直接定性为新增实现 bug。

建议的下一步是审计语义后进行受控权重/时序诊断，不是一口气把 Q 全调小；初始静止标准差小也不能代表运动时所有误差都小。

## 4. ba 与 g 均没有被永久锁定

`IMUInit` 设置 bg 为平均角速度，没有从单一静止姿态求出独立三轴 ba；新滤波器的 ba 初值为 0。加速度进入传播前还有 `9.81 / |mean(a)|` 的标量归一化，不能据此认为三轴 bias 和 scale 已完全校准。

`get_f` 显式使用 `R(a−ba)+g`。`df_dx` 中速度对 ba 的导数为 −R，速度对 g 的导数为 S2 的 Mx；`df_dw` 中 ba 有独立噪声驱动。虽然激光 H 的直接列仅为位姿/外参，完整 Kalman 增益会借助交叉协方差更新速度、bias 和重力方向。

运行证据同样排除“ba 被锁住”：前雷达设备旋转组首个状态 ba≈0，末状态 ba≈[−0.0102105, −0.0004836, −0.0257049] m/s²；g 也从近似 [0,0,−9.809] 变为 [−0.0698474,−0.0649799,−9.8085361]。这些是估计值变化，**不能当作已标定的真实 bias 或断言 g 的变化本身就是 bug**。

初始姿态、ba 和重力在弱激励/弱几何下可能相互解释观测误差。单次静止均值不足以独立辨识全部量，不建议通过冻结 g 或强制水平地面掩盖问题。

## 5. 去畸变与匹配核查

去畸变按相邻 IMU 的均值和实际 dt 传播，用逐点 curvature 毫秒转换为秒，并包含旋转、速度/加速度平移和 LiDAR–IMU 杆臂；历史注释说“only rotation”，实际公式并非仅旋转补偿。

同步器等到最新 IMU 已覆盖扫描末端，但送入当前量测组的是 ≤扫描末端的样本；最后不足一个采样间隔的部分使用最后输入外推至末端。当前默认路径没有新 gap guard，稀疏时这个预测假设会延伸到较长缺口。源码里的 `note*(end−imu_end)` 写成绝对时间差；正常同步不应出现 imu_end > end，不能脱离该前提就认定发生反向积分错误。

匹配仍是局部点面残差和最近邻。低残差只说明对当前地图局部一致，不等于竖直方向有独立真值约束，也不保证大走廊长距离无累计变形。此次没有增加场景先验。

# D1 Max：一楼—楼梯—二楼全局规划

2026-09-23 验收版本。当前完成的是离线静态地图上的全局规划、三维选点和 RViz 预览，不是实机自动上楼控制。

## 如何使用

```bash
cd /home/dndx/d1max_nav_ws
./start_pct_preview.sh start --config /home/dndx/d1max_nav_ws/src/d1max_pct_planner/config/preview_crossfloor_complete.yaml
```

如果已有这个预览服务，先运行 `./start_pct_preview.sh stop`，再启动。停止只清理该预览所属的进程。通信保持 `rmw_zenoh_cpp`，使用独立的本机 Zenoh 路由；不连接 SDK、不发送速度。

RViz 启动后直接显示已复核的完整跨层路线及两个三轴手柄。可拖动起点、终点的 X/Y/Z 轴，放到一楼或二楼有效地面，再点击 Plan。自动选择模式允许同 XY、不同 Z 选择不同楼层。需要时使用楼层/切片锁定辅助选择；PCT 切片编号不等于建筑楼层编号。选点落在空中、墙上或缺测区域时仍会拒绝，不会偷偷移动到另一层。

- 同楼层目标：只在该层地面范围内规划。
- 一楼到二楼：一楼路径、下梯段、平台、上梯段、二楼路径。
- 二楼到一楼：复核后的反向空间路线。这里只证明静态几何连通，不证明机器人下楼步态/动力学可行。
- 绿色到黄色是可通行表面的代价，红色是真正被当前地图规则拒绝的表面。中间高度仅在楼梯区域显示，避免把全楼的桌面/楼板切片混入楼层视图。
- 原始定位 PCD 没有覆盖。当前规划副本用 `d1max_multifloor_planning`，不能冒充原定位坐标系或直接替换定位地图。

## 完整处理链

1. 以修正跨层错误回环后的 SC-PGO 地图为基础，先进行保留建筑结构的点云清理。
2. 独立处理两个楼层的地面与近地杂点，保留约 3.8 m 的楼层高差。楼梯保护区域不做地面压平。已有机器人轨迹仅用于寻找有实测支撑的地面，不直接把轨迹周围涂成可通行。
3. 在楼梯区用关键帧多时刻的 free/hit 观测筛掉瞬时残影，显式保护审查过的西侧墙和二楼楼板边缘。当前扫描缺少逐点雷达身份和完整发射原点，因此这是本地图专用的离线修订，不是已经验证通用性的动态物体识别器。
4. 修复导出降采样引起的地面覆盖丢失：二楼补回 325 个真实扫描点，一楼补回 709 个真实扫描点。一楼补点沿用原来同一地面高度场的 Z 修正并保留残差。每格至少 5 个独立关键帧、同层高度跨度不超过 8 cm；记录真实帧号、点序号、位姿和源文件哈希。没有凭空插值生成地面。
5. 生成 10 cm 的 PCT 分层地图，层间切片间距 0.5 m。楼梯实测约 25°，原来的 0.4 rad 坡度阈值不足；本图采用 0.6 rad、最大单级高度 0.17 m。安全/代价膨胀参数分别 0.10 m，尚未做 D1 Max 实机轮廓认证。
6. 四段分别调用原生 PCT A* + GPMP，楼层内使用独立校验的走廊平滑，楼梯不以额外平滑“挽救”无效曲线。最终检查每一段、完整拼接路径、每次换层位置和上下楼高度顺序。代价 >20 仍拒绝，五次曲线仍逐格验证。

关键修复不是继续降低障碍阈值。10 cm 格子缺少二楼地面时，PCT 会取到下面一层的点，产生约 1.4 m 的假断崖；一楼缺点也会放大成坡度障碍，再经膨胀封住走廊。恢复真实地面采样覆盖，才消除了这类误判。

## 可复现配置

入口：`tools/pointcloud_preprocessing/configs/sc_pgo_0923_crossfloor_complete.yaml`。

```bash
cd /home/dndx/d1max_nav_ws
PYTHONPATH=/home/dndx/d1max_nav_ws:/home/dndx/d1max_nav_ws/src/d1max_pct_planner \
  python3 -m tools.pointcloud_preprocessing.crossfloor_pipeline \
  --config tools/pointcloud_preprocessing/configs/sc_pgo_0923_crossfloor_complete.yaml
```

配置管理楼层处理、可见性证据及结构保护、实测点恢复、PCT 参数、连接区域和路径参数。处理会校验既有证据文件及来源；来源发生变化则停止，不能把这一包数据的缓存套到另一张地图。新地图需要重新提取关键帧证据、配置楼层和楼梯连接区域。

所有输出用新目录保存，包括处理后 PCD、PCT、来源清单、逐点来源、实际入口偏移、路径 CSV 和检查结果；不覆盖原始 PCD。当前正式输出目录为 `maps/processed/sc_pgo_20260923_crossfloor_complete_001`，预览采用该目录的 `route_001/audit.json`（补充完整曲线验证信息）。

## 后续实机边界

全局几何路径已跑通；实机执行还需要定位坐标对接、在线障碍感知、SCAN/跟踪器、楼梯模式切换与急停等闭环验证。规划副本的地面 Z 做过非刚性修正，不能用一个固定 TF 宣称完全等价于原始定位地图。完成这些之前，不自动向机器人下发当前路线。

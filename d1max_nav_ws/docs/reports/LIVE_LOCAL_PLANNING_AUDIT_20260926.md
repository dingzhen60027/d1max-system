## 确证问题与改动

1. 红色局部地图 3 Hz 发布，但 RViz Decay Time 为 0.25 s，正常更新之间必然空白。改为有限 0.75 s；失败诊断 Marker 同代次使用稳定 ID 覆盖和差分删除。真实失效/取消仍清除，不延长轨迹授权。
2. 250 ms 预测跨度错误地在消费者处计入传输延迟。改为检查原始 `posterior→target` 积分跨度，另行检查 target 的原始 80 ms TTL、当前 IMU 时效。非故障 `lio_stale` 不提前撤销上一条仍新鲜的真实样本；不伪造 50 Hz、不重发旧姿态或重写时间戳。
3. A* 对负偏移使用整数截断，取整不对称。改为对称量化，保留端点及连接段碰撞检查。
4. 碰撞查询把实际查询点所在的整个体素也扩张了一次。改用精确圆柱中心到占据体素 AABB 的 XY 距离；完整 Z 体素和接触边界仍保留。缓存键绑定精确 XY、Z 范围及当前地图版本，非法数值拒绝。
5. 起点占据、目标占据、搜索格端点受阻、地图外和未知空间不再统一显示“未找到绕行通道”。新增有界、限频的端点碰撞分类日志，Web/RViz 同步映射，失败状态不能冒充成功轨迹。

# 当前待办与验收边界

截至 2026-09-26 源码整理。本仓库保存工程进展及其验证边界，不代表定位、规划和运动闭环已经全部验收。

## 当前确认的阻塞与限制

1. **近身占据和未知空间仍阻塞局部规划。** 已修正显示时效、A* 量化和额外 XY 膨胀，并接入双源逐束射线；真实录包离线复现中，149 个有效周期的起点仍全部阻塞。末次查询累计 occupied 1 / unknown 1060，含查询体积重叠，不是独立体素总数。近脚回波只能列为疑似自体，不能清空机器人附近空间或将未知空间设为空闲来取得成功轨迹。
2. **机身几何与物理映射未验收。** `body_height_calibrated`、`collision_envelope_validated`、`vertical_envelope_validated` 和 `sdk_speed_mapping_validated` 仍为 false。双圆柱是近似包络，尚未验证能否覆盖动态腿部、自体姿态及连续扫掠体积；地面支撑检查也不是落脚/跌落安全证明。
3. **关节遥测未取得有效数据。** 2026-09-26 经授权的一次只读 SDK 重连中，配置请求已发送，但没有 ACK、关节 `samples=0`；普通状态和 MC 仍在更新。接口缺少源采集时间，只能标注 receipt-only。没有可用于动态自体过滤的实测、同步关节姿态，不能据此断言具体固件故障原因。
4. **当前逐束感知仅用于预览。** `per_sensor_rays` 保留每源原点、逐点时间、独立时效并进入原生滚动地图；`prepare_motion` 明确拒绝该后端的运动模式。整条链仍未通过真实运动跟踪和碰撞安全验收。全局/局部 RViz 两套布局仅改变呈现，不增加运动许可。
5. **SCAN 论文能力未全部落地。** 原生滚动地图、A* 与 B 样条已接线；论文 V-C 的虚拟边界层死路恢复，在已核对的公开 `main` / `ros2-community` 和本地实现中未找到，不能称为已经启用的 fallback。当前 A* 的高度处理、离散碰撞检查和跨层路径支持均有实现边界。

详细证据按阶段记录在 [2026-09-26 局部规划审计](../d1max_nav_ws/docs/LIVE_LOCAL_PLANNING_AUDIT_20260926.md)。其中较早的单一射线原点描述已被后续双源逐束支路更新；较早的会话、PID、测试和部署状态不是本次发布整理的实时状态。

## 仍需实机验收

- SDK ↔ 机身 ↔ 雷达/IMU 的物理外参、轴向、杆臂与时间对齐。未验收标志不能因预览路径生成而修改为已通过，`navigation_ready` 也不能等同于界面“已定位”。
- 静止漂移、加减速/转弯、振动、遮挡、走廊退化、快速运动和长时间断续运行。已有合成测试不是实机厘米级精度或高速上限证明。
- 实机出现过 IMU 时间间隔超限及有界重初始化。恢复机制不等于上游缺帧原因已消除；现有记录不足以单独归责发布端或网络。
- APP 退出后的 SDK 接管已有状态机及离线回归；APP 往返切换、超时/迟到回执和长期 MC 稳定性仍需现场验证。一次接收约 50 Hz 不能保证所有会话一直正常。
- 地图本身的地面倾角、重复结构、处理后几何保真和栅格可通行性；不能靠压平点云或补造障碍来冒充标定/通行性验证。

## 工程整理后仍保留的限制

- 此仓库是源码快照，不是跨机器一键部署包。旧脚本仍有本机绝对路径，部分浏览器验收脚本使用本机 Go2 的 Playwright；需配置环境后运行。
- Foxglove JSON 是之前的导出文件，云端/桌面布局修改不会自动写回 Git。本次没有更新在线布局。
- 历史 UI 构建曾提示 Three.js 点云分块大于 500 kB；本次整理未对该性能问题重新验收。
- 模块内 `VERIFICATION.md` 和交接文件按日期保留历史；其中“已停止”“未提交”等是当时事件，不是当前服务或 Git 实时状态。
- 第三方源码和控制实现保留来源、许可证及验收边界。当前已有原生 PCT / SCAN 预览接线；这不能视为 Nav2 实机执行、跨层行走或楼梯导航验收完成。

后续定位修改应先针对上述边界设计回归，再在用户授权的实机连接条件下验收；不要把 Git push 成功作为机器人功能验收。

# Changelog

## 0.7.4 — 2026-09-10 · 恢复 PCD 窗口并选择单层图

- 恢复原来的左 PCD / 右实时感知分栏，地图数据禁用时仍保留空窗口。
- 按用户后续要求加载 8 月 25 日的 497,844 点单层候选，左侧按新包围盒适配视角；不加载历史多层点云。
- 保留当前实时视角、底部面板配置和精确分割比例；不重启机器人监控，不改原 PCD，不启动导航。

## 0.7.3 — 2026-09-10 · 单楼层调试入口

- 从实际布局移除历史多层 PCD 视图，刷新释放其渲染内容；不自动加载替代地图。
- 新增静态 PCD 总开关，默认禁用；后续启动和布局构建跳过历史文件，保留原文件与视图备份。
- 整理 8 月 25 日单层候选及同次原始前端 PCD，核对轨迹高度、点数与回环日志；不把文件名 optimized 当成回环成功。

## 0.7.2 — 2026-09-10 · 紧凑双电池

- 两个大型电量圆盘改为同一小分组内的两条原生横向电量条，同时可见，保留红黄绿与 0–100% 刻度。
- 电池分组默认布局占比从 15.84% 缩至 4.8%；点云铺满上方，视频、曲线、电池和状态/急停集中在底部一排，保留足够刻度空间。
- 保留原有 3D 视角、数据来源、去重规则与只读/单向急停边界。

## 0.7.1 — 2026-09-10 · 去重与电量语义配色

- 移除纵向、横向、角速度的重复 Gauge，只保留两组原生速度曲线。
- 双电池改为相同的 0–100% 红→黄→绿色标；保留百分比与刻度，不再用蓝/金区分电池。
- 单屏由 12 个面板缩为 9 个，右侧只保留双电池和状态/单向急停；不修改机器人控制逻辑。

## 0.7.0 — 2026-09-10 · 单屏图形仪表

- 合并为无分页的 12 个原生面板：PCD、雷达/图像、前后相机、两组速度曲线、五个仪表与图标急停区。
- 删除主界面的文字卡片、状态列表、JSON 配置和导航标签；保留必要单位、图标悬停含义和短急停标签。
- 使用原生 Gauge / Plot；SDK 过期且监控心跳仍有效时清空仪表，不生成假历史。
- 统一配置单屏比例、量程、颜色；保留用户已有 PCD / 实时感知视角与旧布局备份。
- 运动控制、急停解除和 URDF 仍禁用；没有改动机器人端控制逻辑。

## 0.6.0 — 2026-09-10 · 轻量状态与感知

- 移除操作页及运动、控制权、模式切换、复位和解除急停入口；停用旧控制启动器。
- 使用独立监控接收器，只保留单向软件急停 Trigger；无速度或运动接口。
- 新增只读 PCD 发布器与 map-view.yaml，静态建筑地图和实时感知并排显示，未伪造定位 TF。
- 移除 URDF/STL、模型页及资源服务；原始模型和 PCD 文件保留。
- 状态与急停区贯穿所有标签，已触发的急停显示实机状态，不重复发送。
- 修正实机连接重置被误认作回放的问题；实际 /clock 与后台回放标记仍禁用急停请求。

## 0.5.0 — 受保护控制链路（实机切换待网络恢复）

- 新增独立、可离线测试的 SDK 控制状态机与 console 接收器，不修改原控制桥，不自动执行动作。
- 站立中不算完成；ACK 与两份新 RobotState 分开确认，逐步转换，禁止转换期间叠加普通目标。
- 面板新增动作许可、转换进度、模式切换、锁定姿态的显式解锁、异常人工复位。
- 速度改用专用带会话校验的消息；SDK 端增加独立心跳/速度看门狗，断连不续跑、恢复急停不续跑。
- 实机和回放启动分离，WebSocket 仅开放网关会话白名单；模拟 SDK 不含供应商库、不连接机器人。
- 本地安装与隔离测试已完成；本次发现有线网卡 DOWN，尚未替换实机只读进程或做实机动作验收。

## 0.4.1 — 合并感知场景

- 双雷达点云、前后图像弧面、URDF 合并到原来的“感知总览”3D 场景。
- 移除独立“环绕感知”标签及其专用面板；保留总览视频小窗、SDK、诊断和模型页。
- 图像弧面默认 72% 不透明度，可在 cameras.json 配置；不修改雷达/相机标定或 SDK 接收器。

## 0.4.0 — 前后图像弧面与 SDK 只读遥测

- 新增 Foxglove 原生“环绕感知”页，前后相机分别投影到弧面；保留原来的四个实机标签页。
- 视场采用产品规格书标称值，安装点来自 URDF，明确标注未标定和侧面盲区；参数集中到 cameras.json。
- 增加独立 SDK 被动遥测可执行程序，不注册动作服务，不订阅速度指令，不申请/释放控制权。
- 接通约 1 Hz 的速度、电池、姿态、急停状态和故障消息；未测量的控制就绪/故障锁存保持未知。
- 新增生成脚本语义类型检查、图像分辨率/时间戳/光轴及只读 API 白名单测试。
